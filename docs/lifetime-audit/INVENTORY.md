# Lifetime audit — current master, 2026-10-13

Baseline: `91b8986c`, freshly fetched `PrismLibrary/Prism` master. Branch: `audit/lifetime-collection`. This is an isolated checkout, not the user's modified working tree. PR3442 (`b5716edb576ef5fcc12c1677aa935d2bc4168aae`) is not included or modified. No production fixes, merges, releases or device/Mac tests are part of this change.

Finite collection tests establish behavior for their tested root and host combinations. They do not establish that Prism's entire API is leak-free. Source-backed leads below remain distinct from executable failures.

## Method

Tests use non-inlined creators, weak references, forced full collections/finalizer drains and explicit `GC.KeepAlive` on roots. Helpers return before collection assertions. No elapsed-time sleep is used as collection evidence. Strong ownership controls must remain alive; teardown controls must collect. Queue tests retain callbacks before deterministic draining, then assert collection. Churn runs 16 platform cycles or 32 Core subscription/command cycles.

`Lifetime=KnownRetention` marks intentionally failing regression reproductions on unchanged master. They are neither skipped nor silently accepted. Select `Lifetime!=KnownRetention` for controls; select `Lifetime=KnownRetention` to reproduce failures. An unfiltered suite on this audit branch is expected to fail these reproductions. No CI configuration changes conceal them.

## Demonstrated retention and recommendations

1. **Core nested observer after clearing child.** `ClearingObservedChildShouldReleasePreviousChild` fails when a long-lived owner clears `Child`. Root: owner → `PropertyChanged` delegate → `PropertyObserverNode` root → `Next` node → stale `_inpcObject` → former child. `UnsubscribeListener` detaches the child's handler but does not clear that field; null prevents `GenerateNextNode` from replacing it. Replacement with a non-null child passes collection. Recommendation: evaluate clearing each unsubscribed node's source reference, preserving nested re-subscription and notification semantics. This is not an instruction to unsubscribe all observers.
2. **WPF abandoned bare region host.** `AbandonedBareHostShouldReleaseDelayedBehaviorAfterRealUpdate` first proves host collection, invokes actual `RegionManager.UpdateRegions`, then fails behavior collection. Root: static `DelayedRegionCreationBehavior._instanceTracker` → behavior → adapter mappings. `UnWireTargetElement` only untracks if weak target still exists. Recommendation: make tracker removal independent of target liveness; test successful live creation, repeated attach/detach and abandoned-host churn. WPF execution proves WPF; shared source alone does not prove Avalonia/Uno execution.
3. **Disposed desktop module manager.** `DisposedManagerShouldCollectWithCustomLoaderPublisherAlive` loads through a retained non-disposable custom loader and disposes manager. Loader events strongly own manager. `ModuleManager.Dispose(bool)` disposes disposable loaders but does not detach subscriptions. The final fixture completes the load synchronously before disposal so unfinished work is not the intended owner. Recommendation: remove manager's loader subscriptions at disposal and verify late events and idempotent disposal; do not rely on custom loaders clearing events.

No production change should be shipped solely from this audit. These regressions should accompany separately reviewed fixes with baseline failure and fixed pass evidence.

3. Qualify platform hosts separately: WPF net10 Windows, Avalonia native/headless hosts, Uno managed/Desktop/WinUI/browser and MAUI native Windows. Android/iOS/Mac/device work requires separate authorization/environment.
4. Decide removed-live-region notification and retained default-instance ownership contracts before introducing lifecycle disposal changes. Test late events against old/current region explicitly.
